# Logo KulinerKit

Jalankan `npm run brand:export` dari root proyek untuk membuat ulang PNG dari
lockup `kk` landing page: hijau `#1d5542`, putih gading `#fbf9ed`, hijau muda
`#c8dca6`, teks `KulinerKit`, dan submerek `by LRMobileID`.

- `kulinerkit-profil-1080.png`: logo lengkap untuk unggahan/foto profil IG dan Facebook; elemen penting berada dalam area aman pemotongan lingkaran.
- `kulinerkit-ikon-1080.png`: ikon `kk` besar yang lebih jelas pada foto profil berukuran kecil.
- `kulinerkit-logo-transparan.png`: lockup horizontal 1600 × 460 px berlatar transparan untuk materi promosi.
